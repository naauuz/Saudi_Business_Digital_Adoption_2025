# Data Dictionary / قاموس البيانات

| Field | العربية | Description |
|---|---|---|
| Economic Activity | النشاط الاقتصادي | Economic activity category used for filtering and comparison. |
| Online Selling % | نسبة البيع عبر الإنترنت | Percentage of establishments using the internet to sell goods and services. |
| Online Purchasing % | نسبة الشراء عبر الإنترنت | Percentage of establishments using the internet to purchase/order goods and services. |
| Cloud Computing % | نسبة استخدام الحوسبة السحابية | Percentage of establishments using cloud computing services. |
| IoT Purpose | غرض استخدام إنترنت الأشياء | Purpose for which establishments use IoT. |
| IoT Usage % | نسبة استخدام إنترنت الأشياء | Percentage associated with a specific IoT purpose and economic activity. |

## IoT Purpose values / أغراض IoT
- Energy Consumption Management — إدارة استهلاك الطاقة
- Building Security — أمن المباني
- Maintenance — الصيانة
- Customer Service — خدمة العملاء
