# Raw Data / البيانات الخام

## العربية
المصدر المستخدم في المشروع:

**الهيئة العامة للإحصاء (GASTAT)**  
**Establishments ICT Access and Usage Statistics 2025**

اسم ملف المصدر المستخدم محليًا:
`Establishments ICT Access and Usage Statistics 2025-AR-EN.xlsx`

الموقع الرسمي:
https://www.stats.gov.sa/


### لماذا ملف Excel الأصلي غير موجود هنا؟
تم ترك الملف الخام خارج الـrepository افتراضيًا لتجنب إعادة توزيع ملف الجهة الرسمية بدون حاجة. يستطيع أي شخص الرجوع للمصدر الرسمي، بينما يحتوي مجلد `processed/` على الجداول النظيفة المستخدمة في التحليل.

### Why is the original Excel workbook not included?
The raw official workbook is intentionally excluded from the repository by default. The cleaned analytical tables used by the Power BI report are provided in `data/processed/`.
